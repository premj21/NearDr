# 🩺 **NearDr**  
**An innovative healthcare solution empowering users to locate nearby doctors, book appointments, and manage healthcare interactions seamlessly.**  
Built with the **MERN stack**, NearDr revolutionizes the way users access and manage healthcare services.  
 
📂 **GitHub Repository**: [NearDr Codebase](https://github.com/premj21/NearDr.git)  

---

## **✨ Features**  
- 🗺️ **Locate Nearby Doctors**: Find healthcare providers in your vicinity.  
- 📅 **Book Appointments**: Schedule appointments with ease.  
- 🛠️ **User-Friendly Dashboard**: Manage appointments and track healthcare history.  
- 📱 **Responsive Design**: Optimized for all devices, ensuring a seamless experience.  

---

## **💻 Technologies Used**  
NearDr is powered by the **MERN stack**, ensuring a robust and scalable architecture:  
- 🛢️ **MongoDB**: NoSQL database for storing user data and appointments.  
- 🧩 **Express.js**: Backend framework for building APIs.  
- ⚛️ **React.js**: Frontend framework for a dynamic user experience.  
- 🌐 **Node.js**: Backend runtime for scalable application development.  

---

## **🚀 Installation Guide**  

### **Prerequisites**  
Ensure you have the following installed:  
- **Node.js** (v14 or higher)  
- **MongoDB**  

### **Setup Steps**  
1. **Clone the repository**  
   ```bash  
   git clone https://github.com/premj21/NearDr.git  
   cd NearDr  

    Install dependencies

# For the backend  
cd backend  
npm install  

# For the frontend  
cd ../frontend  
npm install  

Configure environment variables

    Create a .env file in the backend directory with the following:

    MONGO_URI=your_mongodb_connection_string  
    JWT_SECRET=your_jwt_secret_key  

Run the application

    # Backend  
    cd backend  
    npm run start  

    # Frontend  
    cd ../frontend  
    npm start  

    Access the application
        Open your browser and navigate to http://localhost:3000 to explore NearDr! 🎉
